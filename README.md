# Java University Assignments & Mini Projects

A collection of various Java assignments, exercises, and mini-projects developed during my B.Sc. CSE program (Object Oriented Programming). These projects demonstrate fundamental Java concepts, OOP principles, and basic logic implementations.

## Contents
- **BasicJava / BeginnerJava**: Foundational Java syntax and programming logic.
- **OOP**: Object-Oriented Programming principles and examples.
- **Account / AccountTest / GrossPay**: Basic financial and calculation-based mini-projects.
- **StudentData**: Data handling and structure.
- **ExecutionSteps / W3Resource**: Step-by-step logic execution and problem-solving exercises.
